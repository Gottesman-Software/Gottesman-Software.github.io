04 / REPRODUCIBILITY

What qualifies as verified?

A result is promoted from “measured” to “verified” only when its inputs and provenance can be inspected. Publication alone does not replace this register's independent rerun requirement.

01

Freeze the workload

Record circuit, noise model, timing mode, sample count, device, firmware and software versions.

02

Capture raw evidence

Archive traces, data files, logs, scripts, configuration and calibration details with a run identifier.

03

Reproduce & review

Publish commands, the Git commit and uncertainty or failure modes; repeat the experiment independently.

Comparison boundary

For FPGA latency, separate hardware event-to-decision latency from host command-to-result latency. Do not compare picosecond TDC precision with a low-rate USB logic analyzer. All numbers displayed as Gottesman targets are proposals until measurement artifacts are available.

OPEN SCIENCE

Inspect the work behind the claim.

Reference literature, source repositories and subsequent validation artifacts will remain linked to their precise experimental scope.
