# Homepage image notes

The images in this directory are illustrative editorial assets created for the Gottesman Software homepage.

They communicate the software workflow—simulation, decoder validation, prototype control, and research collaboration—but they are not documentary photographs of Gottesman Software facilities, personnel, or owned photonic quantum hardware. The homepage states this boundary in visible captions and alt text.

Replace `research-collaboration.webp` with an approved photograph of the actual team or research environment when one is available.
